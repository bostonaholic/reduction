Reduction

Reduction works entirely on your machine. It only contacts Anthropic when its local parser cannot confidently work out which ingredients each step uses — and only if you add a key below.

Stored in this browser's extension storage and sent only to api.anthropic.com. Without a key, low-confidence recipes fall back to a plain sequential table.

Every option produces the same table; they differ in how well they work out which step uses which ingredient, and in what Anthropic charges you per recipe. Faster models cost less and are more likely to misread an unusual recipe — the overlay always labels its own confidence either way. Fable 5 needs an Anthropic account with 30-day data retention; on a zero-retention account every request to it fails.
